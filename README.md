# Wonek Video Studio: documentation and examples

Native macOS video editing and short-form content workflows.

Maintained by Arte Soft. [Official website](https://studio.wonek.com/) · [Company](https://arte-soft.com/)

This public repository contains product documentation, reproducible workflow examples and a measurement protocol. It is not the application's source-code repository.

## Product overview

- Organize video work in multi-channel workspaces.
- Turn longer recordings into clips and add subtitles.
- Use local AI models for supported transcription and voice workflows.
- Connect supported generation providers using your own API keys where required.
- Prepare covers, batch video projects and exports for publishing.

## Example: a captioned short from your own footage

1. Import a short video you own or have permission to use.
2. Select a self-contained section and set the desired output aspect ratio.
3. Generate subtitles using the available transcription workflow.
4. Review names, punctuation and timing manually.
5. Export and inspect the beginning, middle and end of the result before publishing.

Local model workflows and external provider workflows have different network and hardware requirements. Record which one you used; do not describe provider-backed generation as offline.
